# UI 骨架：把源码里的界面重画成可截图的 HTML

三套 1600×900 的静态页面骨架，用来还原源码里的界面。**不是设计稿，是截图素材。**

| 文件 | 场景 | 画布 |
|---|---|---|
| `shell-desktop-dark.html` | 中后台管理系统（左侧导航 + 筛选 + 表格）。**默认用这个**——视频本身是深色底 | 满画布 |
| `shell-desktop-light.html` | 同上，浅色。仅当用户明确要求"还原原系统浅色样式"时用 | 满画布 |
| `shell-mobile.html` | 移动端 / 小程序（列表 + 标签页 + 底部栏），深色画布 + 居中的手机 | 手机居中 + 右侧说明 |

## 用法

```bash
# 1) 复制一份到工程目录的 ui/ 下改名（文件名就是截图名）
cp "<skill>/assets/ui-shell/shell-desktop-dark.html" "<工程>/ui/order-list.html"

# 2) 按源码里的"还原清单"改文案（见 references/02-ui-redraw.md）
#    ← 箭头注释标出了所有要改的位置

# 3) 截图
python "<skill>/scripts/shoot_page.py" --in ui --out shots_raw
```

## 改的时候注意

1. **`html,body` 必须保持 `width:1600px; height:900px; overflow:hidden`**。
   截图脚本会把窗口开大一圈再裁到 1600×900，页面自己固定画布才不会裁到内容。
2. **表格用绝对定位切三段**（`.tbar` / `.tbody` / `.pager`，见深色版的注释）。
   用 flex 撑高时，行数一多就会把分页器挤出画面——这个坑踩过。
3. **一张截图一个 html**。要展示同一页面的不同区域，分别做：
   `order-list.html`（列表总览）、`order-detail.html`（详情抽屉）、`order-audit.html`（审核弹窗）。
   视频里用 `focus` 高亮框指向不同区域，比在一张图上硬挤更多信息清楚得多。
4. **数据必须仿真**，不要用真实客户名、真实金额、真实账号、真实内网地址。
5. 中文比英文宽，改完先截图看一眼有没有溢出。

## 深色还是浅色

默认深色。理由：视频场景本身是深色底（`#0f1626`），插一张纯白页面在视觉上会很跳，且在低亮度屏幕上偏刺眼。

原系统是浅色时，两个选择：

- **深色化重绘**（推荐）：结构文案 1:1，配色换成深色。画面统一，但要在解说里说明"界面为按源码结构重绘的示意页面"。
- **保持浅色**：用 `shell-desktop-light.html`。适合"就是要原样"的场合，代价是画面节奏会断一下。

两种做法都**不要**在解说里声称"这是系统实际截图"。
